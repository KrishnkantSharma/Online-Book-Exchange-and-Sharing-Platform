# Online Book Exchange and Sharing Platform

A Java Swing desktop application that lets students exchange and share academic books.

## Features
- User registration and login
- Add, view and manage books
- Book details and exchange requests
- Dashboard for logged-in users

## Tech Stack
- Java (Swing)
- MySQL with JDBC
- IntelliJ IDEA

## Setup
1. Clone this repository
2. Import `bookexchange.sql` into MySQL
3. Open `src/DBConnection.java` and set your own MySQL username and password
4. Add the MySQL Connector/J jar to the project libraries
5. Run `Main.java`
